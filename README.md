# Telegram Post Sender (No Backend)

Локальная веб-страница для отправки постов в Telegram через бота. Один файл, никакого сервера.

![Project Screenshot](./screenshot.png)

## Что это

Страница шлёт сообщения в каналы, чаты и группы Telegram через Bot API прямо из браузера.
Всё работает на чистом frontend (`index.html`) — ни backend, ни базы данных, ни сборки.

## Возможности

**Пост**

- Текст (`sendMessage`), картинка (`sendPhoto`), видео (`sendVideo`), файл (`sendDocument`)
- Альбом (`sendMediaGroup`) с миксом фото и видео, из URL и локальных файлов одновременно
- Разметка HTML и MarkdownV2 с панелью форматирования: жирный, курсив, подчёркнутый,
  зачёркнутый, спойлер, моноширинный, цитата, ссылка
- Живой предпросмотр поста в виде сообщения в канале
- Счётчик символов с лимитами Telegram (4096 для текста, 1024 для подписи)
- Опции: без звука, запрет пересылки, отключение превью ссылок
- Файлы можно перетащить мышью на карточку поста

**Получатели**

- Добавление нескольких чатов сразу — через запятую или с новой строки
- Названия каналов подтягиваются через `getChat` вместо голых `-100…` идентификаторов
- Выбор получателей чекбоксами, массовое выделение

**Кнопки**

- Визуальный конструктор inline-кнопок с настройкой числа кнопок в ряд
- Эмодзи-маркеры для визуального выделения кнопки
- Перестановка кнопок и проверка ссылок

**Рассылка**

- Отправка в выбранные чаты с настраиваемой случайной паузой
- Локальный файл загружается в Telegram один раз: остальные чаты получают его по `file_id`
- Автоматический повтор при ошибке 429 — пауза берётся из ответа Telegram
- Отмена рассылки на середине, прогресс и итоговая сводка
- Понятная расшифровка ошибок Bot API вместо сырых описаний
- Горячая клавиша <kbd>Ctrl</kbd>/<kbd>Cmd</kbd> + <kbd>Enter</kbd>

**Прочее**

- Шаблоны постов, автосохранение черновика
- Экспорт и импорт списка чатов и шаблонов в JSON
- Светлая и тёмная тема

## Запуск

1. Скачайте `index.html`.
2. Откройте его в браузере.
3. Введите токен бота и нажмите «Проверить бота».
4. Добавьте каналы, отметьте нужные, заполните пост и отправьте.

## Требования

- Современный браузер (Chrome, Edge, Firefox, Safari)
- Доступ к `https://api.telegram.org`
- Бот добавлен в канал или группу и имеет права на отправку сообщений

## Ограничения Telegram

Это ограничения самого Bot API, а не страницы:

- **Кнопки нельзя покрасить.** У `InlineKeyboardButton` есть только текст и ссылка —
  поля цвета или стиля в API не существует. Выделить кнопку можно эмодзи-маркером.
- **Альбом не носит кнопки.** `sendMediaGroup` не принимает `reply_markup`, поэтому
  кнопки уходят отдельным сообщением сразу после альбома.
- **Альбом — от 2 до 10 элементов.**
- **Файлы не сохраняются в шаблонах** — браузер не даёт сохранить содержимое
  выбранного файла между сессиями. URL-адреса медиа в шаблон попадают.

## Безопасность

- Токен хранится в `localStorage` браузера и уходит только на `api.telegram.org`.
  В шаблоны и в экспорт настроек он не попадает.
- Открывайте страницу локально, с `file://`. При открытии с хостинга страница покажет
  предупреждение: там токен доступен любому постороннему скрипту.
- Токен бота даёт полный контроль над ботом — не публикуйте его.
- Для продакшена нужен backend с безопасным хранением секретов.
